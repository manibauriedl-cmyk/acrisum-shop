Installation

  • Datei speichern und öffnen (Windows).
  • Den Schritten im Setup folgen — kein Administrator nötig.
  • Bei SmartScreen: „Weitere Informationen“ → trotzdem ausführen (selbst signiertes Zertifikat).
  • Norton / Telekom-Sicherheit: kann das Setup als „Verdächtige Datei“ blockieren — das ist ein Fehlalarm bei neuen, noch wenig bekannten Programmen. In Norton: Details → Datei zulassen / Ausnahme für Acrisum-Launcher-Setup-1.2.0.exe. Danach Setup erneut starten.
