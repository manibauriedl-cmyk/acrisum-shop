Installation — Schritt für Schritt

Danke fürs Vertrauen — gleich geht’s los. Windows kann beim ersten Start eine blaue Vorsichtsmeldung zeigen. Das ist normal, kein Fehler und kein Virus.

Alles in Ordnung: Ihre Setup-Datei ist mit Certum Code Signing signiert (Herausgeber: Manfred Adalbert Bauriedl). Windows kennt uns als Herausgeber noch nicht überall — deshalb die extra Vorsicht. Sie müssen nichts Besonderes installieren, nur einmal durchklicken.

  1. Oben auf Setup herunterladen — Datei speichern und doppelklicken.
  2. Blaue Meldung? Weitere Informationen → Trotzdem ausführen.
  3. Im Assistenten Weiter bis Fertigstellen — kein Administrator nötig.

Tipp: Die Leiste erscheint gleich am Bildschirmrand. Kein Internet nötig — alles steckt im Setup.

Falls etwas blockiert

  • Norton / Telekom-Sicherheit: meldet manchmal „Verdächtige Datei“ — Fehlalarm bei neuen Programmen. In Norton: Details → Datei zulassen / Ausnahme für Acrisum-Launcher-Setup-1.2.12.exe. Danach Setup erneut starten.
  • Fehler 5 / Temp-Ordner (oft Windows 8.1): Norton sperrt das Entpacken. Norton kurz pausieren und Setup erneut. Protokoll: Setup-Datei in eine Eingabeaufforderung ziehen und dahinter schreiben: /LOG="%USERPROFILE%\Desktop\acrisum-setup.log" — Log liegt dann auf dem Desktop. Oder ACRISUM-PROTOKOLL.cmd speichern, doppelklicken — schreibt acrisum-protokoll.txt auf den Desktop (USB mitnehmen, nichts abschreiben).

Ausführliche Erklärung auch auf der Startseite unter Installation.
