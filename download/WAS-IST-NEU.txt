Launcher 2 — Hinweise zur Version 1.2.15
=======================================

Datum: 21.09.2026


Was sich für Sie ändert
-----------------------
• Website in der Leiste: Der Launcher liest die Adressleiste im Browser
  (Chrome/Edge). Steht dort eine andere Seite als beim Pin, wird kein
  falscher Tab angesprungen — z. B. öffnet „Website“ nicht mehr den
  internen Shop, wenn Sie schon auf acrisum.com sind.
• Fehlerbericht: Bei einem Problem können Sie uns per E-Mail schreiben —
  Sie sehen den Text vorher, persönliche Pfade werden maskiert.


Stand 1.2.14 (19.09.2026)
-------------------------
• Installation: Sie wählen „nur für mich" oder „für alle Benutzer".
  Beim Ordner C:\Programme fragt Windows einmal nach Rechten.
• Der Zielordner wird vor dem Kopieren angelegt und probehalber
  beschrieben — klare Meldung statt allgemeiner Setup-Fehler.
• Liegen Desktop-Symbole unter der Leiste, schiebt sie der Launcher
  frei — auch wenn kein Platz reserviert ist.
• Beschriftung: Das erste Zeichen langer Namen wurde abgeschnitten —
  jetzt steht der Name vollständig.
• Die Leiste startet etwas größer (Ansicht 8 von 13 statt 3 von 13).
  Einmal eingestellt, bleibt Ihre Größe.


Stand 1.2.13 (10.09.2026)
-------------------------
• Ordner, Programme oder Verknüpfungen aus dem Explorer auf die Leiste
  ziehen — hängt an (wie PowerToys, aber Klick startet direkt).
• Fenstervorschau (Hover) weiterhin nur in der orangen Entwicklungs-Leiste.


Stand 1.2.12 (09.09.2026)
-------------------------
• Diese Version sitzt nur auf dem Hauptbildschirm. Bei mehreren
  Bildschirmen erscheint einmal ein Hinweis. Ziehen auf andere Schirme
  holt die Leiste zurück — Desktop-Symbole dort bleiben auf ihrem Schirm.
• Neue Versionen kommen von selbst. Nach dem Start prüft der Launcher
  kurz auf acrisum.com. Ist etwas Neues da: ein Klick auf Aktualisieren.
• Python (die unsichtbare Laufzeit) kommt im selben Schritt mit.
  Sie müssen keine Ordner kopieren.
• Update prüft die Installation — klare Meldung statt kryptischem
  „Python nicht gefunden“, wenn etwas schiefging.
• Ihre angehefteten Programme und die Lage der Leiste bleiben.
• Windows 8.1: Start vom Desktop und Startmenü. An die Taskleiste
  anheften geht dort nicht — das ist eine Windows-Grenze, kein Fehler
  des Launchers.
